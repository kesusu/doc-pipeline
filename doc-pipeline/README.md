# doc-pipeline — Scanned PDF to Editable Word with LaTeX Formulas

[中文文档](README_CN.md) | Claude Code skill: OCR + Document Conversion

**Scanned PDF / images → editable Word with double-click math formulas.** One command, full pipeline.

> Digitize textbooks, convert exam papers, process lecture notes. Works with PaddleOCR + pandoc.

## Core Features

- **OCR text recognition** — PaddleOCR API, supports scanned PDF and images, async polling for multi-page documents
- **LaTeX → editable Word formulas** — pandoc `--mathml` renders formulas as Office Math (OMML), fully editable in Word by double-clicking
- **Word formatting enforcement** — headings stay with next paragraph (keepNext), table rows won't split across pages (cantSplit), widow/orphan control, default table borders
- **Chinese font control** — forces SimSun/SimHei/Times New Roman, overrides Word theme fonts, per-platform font names
- **Cross-platform** — Windows / macOS / Linux, auto-detects pandoc and Python
- **Three modes** — OCR only, Convert only, or Full pipeline (OCR → Word in one command)
- **Claude Code integration** — type `/doc-pipeline` and Claude handles everything

## Use Cases

| Scenario | Mode | What you get |
|----------|------|-------------|
| Textbook PDF with formulas → editable Word | C (Full) | Editable text + math in Word |
| Exam paper scan → Word for editing | C (Full) | Re-typable exam document |
| Already have Markdown notes → Word | B (Convert) | Formatted Word with formulas |
| Lecture slides (images) → text | A (OCR) | Markdown with embedded images |
| Research paper scan → searchable text | A (OCR) | Extracted text for further processing |

## Prerequisites

| Dependency | Required for | Install |
|------------|-------------|---------|
| Python 3.8+ | All modes | [python.org](https://python.org) |
| [pandoc](https://github.com/jgm/pandoc/releases) | Mode B, C | `winget install JohnMacFarlane.Pandoc` (Win) / `brew install pandoc` (Mac) / `sudo apt install pandoc` (Linux) |
| pip packages | All modes | `pip install requests python-docx lxml` |
| PaddleOCR API Token | Mode A, C | Free registration at [aistudio.baidu.com](https://aistudio.baidu.com/paddleocr) |

Mode B (Markdown → Word only) does **not** need an API token.

## Installation

```bash
# 1. Clone or download
git clone https://github.com/YOUR_USERNAME/doc-pipeline.git

# 2. Copy to Claude Code commands directory
cp doc-pipeline.md ~/.claude/commands/
cp -r doc-pipeline/ ~/.claude/commands/

# 3. Install Python dependencies
pip install -r ~/.claude/commands/doc-pipeline/scripts/requirements.txt

# 4. Install pandoc (see table above)
```

**5. Configure OCR (only for Mode A/C; Mode B doesn't need this)**

1. Go to https://aistudio.baidu.com/paddleocr
2. Click "API" and choose your OCR model (the author uses PaddleOCR-VL-1.5)
3. The site gives you sample code — **copy the whole thing and paste it to Claude**, it will extract the token and configure everything for you

Using a different OCR service? Just paste your API details to Claude, it'll handle the rest.

The Python scripts work independently:

```bash

# Convert only
python scripts/convert.py markdown_dir/ docx_output/
```

## Configuration

### Font Settings

Edit `scripts/convert.py` → `FONT_CONFIG`:

```python
FONT_CONFIG = {
    'cn_body': 'SimSun',          # Body text Chinese font
    'cn_heading': 'SimHei',       # Heading Chinese font
    'latin': 'Times New Roman',   # English/numbers/formula font
}
```

Platform-specific Chinese font names:
- **Windows**: SimSun, SimHei, KaiTi, Microsoft YaHei
- **macOS**: Songti SC, Heiti SC, Kaiti SC
- **Linux**: WenQuanYi Micro Hei, Noto Sans CJK SC

### Environment Variables

| Variable | Overrides | Default |
|----------|-----------|---------|
| `PADDLEOCR_TOKEN` | API authentication | (empty — must configure) |
| `PADDLEOCR_MODE` | `sync` or `async` | `async` |
| `PADDLEOCR_SYNC_URL` | Sync API endpoint | PaddleOCR official |
| `PADDLEOCR_ASYNC_URL` | Async API endpoint | PaddleOCR official |

## Security

- **No API keys in source code.** `CONFIG["token"]` defaults to empty string.
- **Your token never leaves your machine.** Configured via environment variable or local edit.
- `.gitignore` excludes `.env`, `__pycache__/`, and all output directories.

## Limitations

- Async OCR: 1–5 minutes for multi-page PDFs
- Sync mode: single-page/small files only (30s timeout)
- Editable formulas require Word 2016+
- Chinese fonts must be installed on the system (Linux users may need manual install)
